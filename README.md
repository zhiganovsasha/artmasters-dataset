# artmasters-dataset

Закрытая страница с результатами исследования базы финалистов ArtMasters.

Содержимое страницы зашифровано и открывается только по паролю.
Пароль выдаётся координатором проекта и в этом репозитории не хранится.

Публикация: GitHub Pages, ветка `main`, корень репозитория.

## Структура

- `index.html` — зашифрованная заглушка (корень).
- `presentation/index.html` — зашифрованная презентация (46 слайдов).

> В репозитории намеренно нет данных, исходников и контактов — только
> зашифрованные HTML-файлы.
